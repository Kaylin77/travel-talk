# 旅途开口 · TripTalk

面向有大学英语基础、缺少语境练习、希望自然开口的移动端网页 App。包含 32 句必备、8 个场景、39 个任务和 241 条表达。首页按中文需求查找；「必备」用于出发前复习；「场景」包含对话、常见变化和接话练习。收藏、掌握记录和选填的旅行信息保存在当前浏览器。

## 本地运行

在本目录运行：

```sh
python3 -m http.server 8765 --bind 0.0.0.0
```

电脑打开 `http://localhost:8765/`。同一局域网内的手机可打开 `http://电脑的局域网 IP:8765/` 预览页面。手机通过局域网 HTTP 访问时，离线缓存和安装功能通常不可用；正式部署需要 HTTPS，`localhost` 可用于本机测试。iPhone 可在 Safari 分享菜单中选择「添加到主屏幕」。

首次访问时需联网。页面的「下载离线内容」会缓存界面、文字、清单和图标；下载完成后可离线查阅这些内容。语音朗读使用设备浏览器的语音功能，声音及离线可用性取决于设备和已安装语音，不属于下载内容。换设备或清理浏览器数据会移除本地记录和离线缓存。
